🌿 Smart Irrigation System – Summary
This smart irrigation system uses soil moisture sensors to detect moisture levels in the soil. 
The sensor readings are sent as analog data to an Arduino Uno, allowing more accurate moisture detection.
Based on programmed conditions, the Arduino decides whether to activate a water pump if the soil is too dry.
A servo motor is used to direct water flow between multiple fields. 
For example, if crop A needs more water than crop B, the servo rotates the water pipe toward crop A first, waters it, and then shifts to crop B when needed. 
This enables targeted irrigation and conserves water.
The system is designed to automatically irrigate plants, helping to maintain proper watering even when the user is unavailable or forgetful.
It minimizes the need for human effort by using automation to handle plant care over extended periods

Components Used:

Arduino Uno

Soil Moisture Sensor

Servo Motor

Mini Water Pump

Relay Module

Breadboard

Jumper Wires
